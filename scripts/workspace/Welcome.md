# Welcome to your workspace

This is the first note of your workspace. Mneme governs this folder: it keeps the history of every note, records which session wrote each change, and lets several AI sessions work here without overwriting each other.

## How to search your notes

Ask Claude Code about something in your notes: in this workspace it searches with Mneme before answering. From a terminal: `mneme search "some words"`.

## How to start

Write notes as Markdown files in this folder, split into sections with headings (`## A section`). Mneme searches, guards and reports changes by section, so small sections work best.

Not sure what comes next? Ask Claude "what is missing?": it checks your install and tells you the next step.

## How to undo it

`scripts\uninstall-windows.ps1` in the Mneme folder removes the hooks and the command. Your notes stay where they are.
